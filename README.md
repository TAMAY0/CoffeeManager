# CoffeeManager - Sistema de Gestión de Pedidos

Sistema para gestionar pedidos en una cafetería usando Python, Streamlit y Pytest.

## Características
- Registro de productos y pedidos.
- Cálculo de subtotal, IVA (13%) y total.
- Interfaz web con Streamlit.
- Pruebas unitarias e integración.
- Despliegue en Streamlit Cloud.
